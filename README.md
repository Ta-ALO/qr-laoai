## ✨ ຄຸນລັກສະນະຫຼັກທີ່ປັບແຕ່ງໃໝ່

- **Mobile Optimized:** ອອກແບບສະເພາະສຳລັບໜ້າຈໍມືຖື (Max-width 520px, Card Stack 1 ຖັນ, ປຸ່ມກົດງ່າຍຂະໜາດໃຫຍ່).
- **Centered Icons:** ໄອຄອນ (Web, Apple, Google Play) ຖືກຈັດຢູ່ເຄິ່ງກາງຢ່າງສວຍງາມ ແລະ ສົມດຸນ.
- **Pure Lao Language:** ເນື້ອຫາທັງໝົດເປັນພາສາລາວ 100% ອ່ານງ່າຍ ແລະ ເຂົ້າໃຈງ່າຍ.
- **Light Theme Only:** ໂທນສີສະຫວ່າງ ສະອາດ ດ້ວຍສີຟ້າເອກະລັກຂອງ LaoAI (`#004dd7`).
- **Smart Device Detection:** ກວດຈັບອັດຕະໂນມັດວ່າຜູ້ໃຊ້ກຳລັງເປີດຜ່ານ iPhone/iPad ຫຼື Android ເພື່ອແນະນຳປຸ່ມດາວໂຫລດທັນທີ.
- **QR Code Lightbox & Copy Link:** ສາມາດກົດສຳເນົາລິ້ງ ຫຼື ແຕະຂະຫຍາຍ QR Code ເພື່ອບັນທຶກຮູບ (PNG / SVG).
